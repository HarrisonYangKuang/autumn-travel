# 台湾部分逐页讲稿

## 第13页｜秋是缓慢的（chapter-taiwan）

刚才我们看到了黑龙江短暂的秋色，也看到了西安城墙边厚重的秋天。接下来来到台湾，秋天的节奏就慢下来了。

这里的秋意，不一定是满山红叶。它可能先出现在阳明山的芒花里，再慢慢出现在水边的树叶上。茶山上的雾，又让人愿意多停一会儿。所以，我们用“缓慢”来形容台湾的秋天。

## 第14页｜秋天先从芒花开始（taiwan-grass）

这一页是阳明山的芒花。秋天，山坡上的芒花在风里摇动，阳光从后面照过来，就会显出一片银白。

北方的秋色常常让人想到金黄和火红，而这里的秋天，是从白色开始的。风吹过山坡，芒花一层一层地起伏，整座山好像也在慢慢呼吸。

## 第15页｜落羽松还没有红（taiwan-cypress）

再看落羽松。北边有些树已经落叶了，这里的树叶却可能还在慢慢换色。

不少地方的落羽松观赏期，会从十二月延续到第二年一月。不过，不同地点、不同年份，转色时间会随气温变化，并不是全台湾都要等到同一天。

画面里还有一个有趣的细节：这些从地面冒出来、像小凳子一样的东西，就是落羽松的气根。这张照片是帮助我们认识气根的示意图。

## 第16页｜把雾推开（taiwan-mist）

（先展示雾中的画面，再移动鼠标擦雾；也可以按 Enter 一次推开。）

接下来，我们一起把雾推开。

雾散开以后，茶园的线条才慢慢出现，一列一列地顺着山坡延伸。这里的风景不是一下子全部展现在眼前的，而是要等一等，才看得更清楚。

这也是我觉得台湾的秋天很特别的地方：它让人放慢脚步，注意那些原本容易错过的细节。

## 第17页｜落羽松的秋冬色彩，何时值得留意？（quiz-taiwan）

最后问大家一个小问题：想看落羽松的秋冬色彩，下面哪个说法更合适？

（请大家看选项，留几秒举手，再点 B 或按数字2。）

答案是 B，常见于十二月至第二年一月。比如桃园南兴落羽松，官方资料给出的最佳观赏期大约是十二月中到一月底。当然，出发之前，还是要看看当地最近的叶色和天气。

从芒花，到落羽松，再到茶山上的雾，台湾的秋天没有那么急。接下来，我们再去香港，看看山与海之间清爽的秋天。
